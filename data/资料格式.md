# 资料格式

sessions 中 observer 可以是家庭成员或站点人员，joint 为多人观察同一场活动时手写的机会编号，留空表示记录员未能关联。turns 自前向后记录，speaker 标签为该听记者的当时判断，audio_missing 标记听记缺口。
- schedule 的 slots 为尚未使用的观察时段，activities 说明活动所支持的表达机会，partners 记录可参与人员及会使用的语言。
- access 的 viewers 限制原话可见对象，child code 只表示记录归属。独立且可比较的观察机会不按笔录份数计算。站点用至少两次独立的主动表达，并且来自家与站两种场合、两个不同伙伴，作为能在家庭沟通中确认跨场景主动的依据。
