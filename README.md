# 家园多语游戏记录的语言证据与观察安排

青谷养育站的合成分轮听记、时段和沟通授权。姓名只用合成代号，资料只服务于游戏安排。

资料为 UTF-8 JSON。各类原始记录按编号分组，字段约定见 [资料格式](data/资料格式.md)。资料浏览命令会原样输出记录，添加 `--list` 可只查看各类数量。

分析工具把分轮原话整理成可比较的观察机会：

- 用上下文把回合区分为孩子主动表达、受提示后的独立表达、直接仿说、成人代述和证据不足（省略主语的连续回合、转换语言、模仿、可解释词形都按上下文判断）；
- 按交际意图归并多语表达（粤语“俾我”与普通话“给我”算同一意图，不另计机会），同一短句在不同场景可承担不同意图；
- 重复转抄关联到同一观察机会，只计一次并标出亲见记录；同一回合不重复算独立证据；
- 机会没有某种表达时，分清“确实给了表达机会但没有发生”“活动没到这一步”“听写者没有记下来”，记录缺口不算没有能力；
- 更正（如家长说明某句是哥哥替答）生效后重算结论，复核已约游戏是否还值得做、已完成游戏保留当时条件重判独立性；
- 只剩一个时段时，按“谁会哪种语言、能做什么活动、哪些伙伴已参与”优先补最影响判断的缺口，一个活动可同时补足关联缺口；
- 家庭只看授权片段和站点可解释的依据，跨场景关联不泄露其他孩子的身份或家庭原话；缺材料时也给出老师可执行的下一次观察问题。

结果只用于安排游戏和与家长沟通，不构成诊断。

使用 Python 3.11，命令只依赖标准库。请在项目根目录运行。

```sh
python3 inspect_records.py data/records.json --list
python3 analyze_records.py data/records.json                 # 站点完整报告
python3 analyze_records.py data/records.json --view teacher  # 教师下一次观察问题
python3 analyze_records.py data/records.json --view family --viewer 家庭芬
python3 -m unittest discover -s tests -v
```
